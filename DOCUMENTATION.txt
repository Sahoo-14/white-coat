================================================================================
  1. PROJECT OVERVIEW
================================================================================

This project delivers a complete, modern, and mobile-responsive website for 
Bhanja College of Nursing located in Bhanjanagar, Ganjam District, Odisha, India.

PURPOSE:
- Provide information to prospective students and parents about nursing courses
- Showcase campus infrastructure, facilities, and academic programs
- Capture admission enquiries through an integrated lead form
- Enable administrative staff to manage notices, gallery, and leads via CMS
- Ensure regulatory compliance visibility (INC, ONMC, OUHS approvals)

TARGET AUDIENCE:
- Prospective students seeking nursing education (10+2 pass)
- Parents and guardians evaluating nursing colleges
- Current students accessing notices and updates
- Administrative staff managing content through the admin panel
- Regulatory bodies verifying institutional information

KEY FEATURES:
- Dynamic hero image slider with auto-advance
- Horizontal announcement ticker for urgent notices
- Interactive notice board with "NEW" badge animations
- Course information with tabbed interface (ANM, GNM, B.Sc. Nursing)
- Photo gallery with category filters and lightbox viewer
- Admission enquiry form with real-time validation
- Contact form with Google Maps integration
- Complete CMS admin panel at /admin
- Fully responsive design (mobile, tablet, desktop)
- Scroll-triggered animations for engaging user experience

================================================================================
  2. TECHNOLOGY STACK
================================================================================

FRONTEND:
  - HTML5 (semantic markup with accessibility considerations)
  - CSS3 (custom properties, flexbox, CSS grid, keyframe animations)
  - JavaScript ES6+ (vanilla, no frameworks or jQuery)
  - Font Awesome 6.5.1 (icon library via CDN)
  - Google Fonts (Inter for body, Playfair Display for headings)

STYLING APPROACH:
  - Vanilla CSS with CSS Custom Properties (design tokens)
  - No CSS frameworks (Bootstrap/Tailwind not used)
  - Modular CSS architecture (4 separate files)
  - Mobile-first responsive design

DATA STORAGE:
  - localStorage (browser-based, persistent across sessions)
  - sessionStorage (admin authentication, cleared on tab close)
  - No server-side database required for demo operation

EXTERNAL DEPENDENCIES (CDN):
  - Font Awesome 6.5.1: https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.1/css/all.min.css
  - Google Fonts: Inter (300-700), Playfair Display (400-700)

  6. ADMIN PANEL (CMS) USER GUIDE
================================================================================

ACCESS URL: Open admin/index.html in your browser
DEFAULT CREDENTIALS:
  Username: admin
  Password: bhanja2026

SECURITY FEATURES:
  - Password validated against hashed credentials
  - Brute-force protection: 3 failed attempts = 5-minute lockout
  - Session stored in sessionStorage (auto-logout on browser close)
  - Auth check on every admin page (redirects to login if unauthenticated)

--- DASHBOARD (admin/dashboard.html) ---

  After login, you land on the dashboard showing:
  - 4 summary stat cards:
    * Total Notices (count of all notices)
    * Total Gallery Items (count of gallery images)
    * Total Enquiries (count of admission leads)
    * New Enquiries (leads submitted today)
  - Recent Notices (latest 5 notices)
  - Recent Enquiries (latest 5 leads)
  - Quick Action Buttons: Add Notice, Add Image, Export Leads

--- NOTICE MANAGEMENT (admin/notices.html) ---

  VIEWING NOTICES:
  - Table showing all notices: ID, Title, Date, Ticker status, Actions
  - Click column headers to sort

  ADDING A NOTICE:
  1. Click "Add New Notice" button
  2. Fill in: Title, Body text, PDF URL (optional)
  3. Toggle "Show on Ticker" to display in homepage announcement bar
  4. Toggle "Mark as New" for the pulsing "NEW" badge on homepage
  5. Click "Save Notice"

  EDITING A NOTICE:
  1. Click "Edit" icon next to the notice
  2. Modify fields in the modal form
  3. Click "Save Notice"

  DELETING A NOTICE:
  1. Click "Delete" icon next to the notice
  2. Confirm in the confirmation modal
  3. Notice is permanently removed

  NOTE: Changes to notices immediately reflect on the homepage notice board
  and announcement ticker the next time a visitor loads the page.

--- GALLERY MANAGEMENT (admin/gallery.html) ---

  VIEWING GALLERY:
  - Grid view showing all images with captions and category badges

  ADDING AN IMAGE:
  1. Click "Add Image" button
  2. Enter Image URL/path (relative to site root, e.g., "assets/images/new.jpg")
  3. Enter Caption text
  4. Select Category: Campus, Laboratories, Clinical Postings, Cultural Events
  5. Click "Save"

  DELETING AN IMAGE:
  1. Click "Delete" icon on the image card
  2. Confirm deletion
  
  NOTE: To add actual image files, upload them to the assets/images/ directory
  on your web server, then add the path through this admin interface.

--- LEAD MANAGEMENT (admin/leads.html) ---

  VIEWING LEADS:
  - Full table: Name, Mobile, Email, Course, PCB%, Address, Date
  - Leads are automatically populated from admission form submissions

  SEARCHING:
  - Type in the search box to filter leads by name, email, or phone

  DATE FILTERING:
  - Set "From" and "To" dates to filter leads by submission date

  EXPORTING:
  - CSV Export: Click "Export CSV" to download all visible leads as .csv
  - Excel Export: Click "Export Excel" to download as .xls compatible file

  DELETING A LEAD:
  - Click the delete icon next to a lead
  - Confirm deletion

================================================================================
  7. DATA STORAGE & MANAGEMENT
================================================================================

All data is stored in the browser's localStorage. This means:
- Data persists across page reloads and browser restarts
- Data is specific to the browser/device being used
- Data is NOT shared across different browsers or devices
- Clearing browser data will erase all stored information

LOCALSTORAGE KEYS:

  Key: 'bcn_notices'
  Type: JSON Array of Objects
  Structure: [{
    id: Number,
    title: String,
    body: String,
    date: String (YYYY-MM-DD),
    isNew: Boolean,
    showOnTicker: Boolean,
    pdfUrl: String (URL or empty)
  }]

  Key: 'bcn_gallery'
  Type: JSON Array of Objects
  Structure: [{
    id: Number,
    src: String (image path),
    caption: String,
    category: String ("campus"|"labs"|"clinical"|"events")
  }]

  Key: 'bcn_leads'
  Type: JSON Array of Objects
  Structure: [{
    id: Number,
    name: String,
    mobile: String,
    email: String,
    course: String,
    address: String,
    physics: Number,
    chemistry: Number,
    biology: Number,
    date: String (YYYY-MM-DD)
  }]

  Key: 'bcn_login_attempts'
  Type: JSON Object
  Structure: {
    count: Number,
    lockoutUntil: Number (timestamp) or null
  }

  Key (sessionStorage): 'bcn_admin_session'
  Type: String
  Value: Session token (any truthy value indicates logged-in state)

DEFAULT DATA:
  On first visit, if localStorage is empty, the system seeds:
  - 6 sample notices with realistic content
  - 12 sample gallery items across 4 categories
  - 0 leads (populated by admission form submissions)

FOR PRODUCTION DEPLOYMENT:
  Replace localStorage operations with API calls to a backend server:
  - PHP + MySQL: Create REST API endpoints for CRUD operations
  - Node.js + PostgreSQL: Use Express.js with Sequelize ORM
  - The frontend admin interface remains identical; only the data layer changes

  8. RESPONSIVE DESIGN BREAKPOINTS
================================================================================

  BREAKPOINT          WIDTH           DEVICES
  Desktop Large       > 1200px        Large monitors, wide screens
  Desktop             1024-1200px     Standard desktop monitors
  Tablet              768-1024px      iPads, tablets, small laptops
  Mobile Large        480-768px       Large phones, small tablets
  Mobile              < 480px         Standard smartphones

  KEY RESPONSIVE BEHAVIORS:

  At 768px and below:
  - Navigation collapses to hamburger menu
  - Hero slider reduces height (350px)
  - Split section stacks vertically (left above right)
  - Gallery grid: 2 columns
  - Footer grid: single column
  - Stats section wraps to 2x2 grid
  - Form fields go full width
  - Admin sidebar collapses (toggleable)

  At 480px and below:
  - Hero slider: 250px height
  - Gallery grid: single column
  - Heading sizes reduced
  - Padding reduced throughout
  - Stats: 1 column
  - Course cards: 1 column

  10. DEPLOYMENT INSTRUCTIONS
================================================================================

  OPTION A: SIMPLE STATIC HOSTING (Recommended for Demo/Testing)

  1. Upload entire "Nursing College" folder to any web server
  2. Point the domain to the folder containing index.html
  3. Ensure all files maintain their relative paths
  4. No server-side configuration needed

  OPTION B: SHARED HOSTING (cPanel-based)

  1. Log into your hosting cPanel
  2. Navigate to File Manager > public_html
  3. Upload all files and folders from "Nursing College" directory
  4. Ensure file permissions: 644 for files, 755 for directories
  5. Set up SSL certificate (most hosts offer free Let's Encrypt)
  6. Configure .htaccess for HTTPS redirect:
     RewriteEngine On
     RewriteCond %{HTTPS} off
     RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]

  OPTION C: VPS/DEDICATED SERVER

  1. Install web server (Apache or Nginx)
  2. Configure virtual host pointing to the project directory
  3. Install SSL certificate (certbot for Let's Encrypt)
  4. Set up proper file permissions
  5. Configure server caching headers for static assets

  DOMAIN SETUP:
  - Register domain (e.g., bhanjacollegeofnursing.ac.in or .com)
  - Point A record to server IP
  - Wait for DNS propagation (24-48 hours)

  POST-DEPLOYMENT CHECKLIST:
  [ ] All pages load correctly
  [ ] Images display properly
  [ ] Forms submit and show success messages
  [ ] Admin panel login works
  [ ] HTTPS is active (padlock in browser)
  [ ] Mobile responsiveness verified
  [ ] Contact information is accurate
  [ ] Google Maps embed shows correct location

================================================================================
  12. SECURITY CONSIDERATIONS
================================================================================

  CURRENT IMPLEMENTATION (Demo Level):
  - Admin credentials stored client-side (suitable for demo only)
  - Data in localStorage (accessible via browser dev tools)
  - No server-side validation (client-side only)

  FOR PRODUCTION DEPLOYMENT:

  Must Implement:
  1. Server-side authentication (PHP sessions or JWT)
  2. Password hashing (bcrypt or Argon2)
  3. CSRF token protection on all forms
  4. Input sanitization on server-side
  5. SQL injection prevention (parameterized queries)
  6. XSS prevention (output encoding)
  7. Rate limiting on form submissions
  8. CAPTCHA on admission and contact forms
  9. File upload validation (type, size, virus scan)
  10. HTTPS enforced via server configuration

  Recommended:
  - Regular security audits
  - Web Application Firewall (WAF)
  - Regular CMS credential rotation
  - Server access logging and monitoring
  - Automated backup system (daily database, weekly full)

================================================================================
  15. TROUBLESHOOTING
================================================================================

  ISSUE: Images not displaying
  SOLUTION: Check that all image files exist in assets/images/ directory.
  Verify file names match exactly (case-sensitive on Linux servers).

  ISSUE: Admin panel shows blank data
  SOLUTION: Clear localStorage and reload. Data will be reseeded with defaults.
  In browser console, type: localStorage.clear() then refresh the page.

  ISSUE: Navigation not working on mobile
  SOLUTION: Ensure main.js is loaded after the HTML. Check browser console
  for JavaScript errors. Verify hamburger button has id="hamburger".

  ISSUE: Announcement ticker not scrolling
  SOLUTION: Check that notices exist with showOnTicker: true in localStorage.
  Verify animations.css is loaded. Check for CSS conflicts.

  ISSUE: Form submission not saving data
  SOLUTION: Check browser console for errors. Verify forms.js and data.js are
  both loaded. Ensure localStorage is not disabled or full.

  ISSUE: Admin login not working
  SOLUTION: Default credentials are admin / bhanja2026. After 3 failed
  attempts, wait 5 minutes for lockout to expire. To reset lockout:
  In browser console: localStorage.removeItem('bcn_login_attempts')

  ISSUE: Gallery lightbox not opening
  SOLUTION: Verify gallery.js is loaded on gallery.html. Check that lightbox
  overlay HTML markup exists in the page. Check console for errors.

  ISSUE: Statistics counter not animating
  SOLUTION: Scroll down to the stats section. Animation triggers only once
  on first view. Verify IntersectionObserver is supported in your browser.

  ISSUE: CSS styles not loading
  SOLUTION: Check file paths in <link> tags. Ensure css/ directory exists
  with all 4 CSS files. Clear browser cache (Ctrl+Shift+R).

  ISSUE: Responsive layout broken
  SOLUTION: Verify responsive.css is loaded AFTER components.css. Check
  viewport meta tag exists: <meta name="viewport" content="width=device-width, initial-scale=1.0">
